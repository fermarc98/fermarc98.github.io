# Personal media

Optional imagery for the Personal Interests section. Drop real photos into the
matching subfolder; until then the section uses text / simple cards.

## Subfolders

- `coffee/`
- `reading/`
- `photography/`
- `sports/`
- `robotics-events/`

## Intended filenames (per interest)

| File | Purpose |
|---|---|
| `cover.jpg` | Card image for the interest (square or 4:3). |
| `demo.gif` | Optional short clip (e.g. an event highlight). |
| `result.png` | Optional supporting figure or photo. |

Keep these tasteful and professional. Do not include any private documents,
ID/permit images, or anything with personal contact details.
